# React Frontend
Here is the source code of the frontend. To test and run it, follow the instructions below.

## Available Scripts
Navigate to the project directory, then run the following commands in order:

Ensure that you have Node.js installed, then run:
  ```sh
    npm install
  ```

After installing all necessary dependencies, you can start the app in development mode: 
  ```sh
    npm start
  ```
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
